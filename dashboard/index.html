Which pre-token protocol is worth farming next?

Every protocol below records no token yet — DefiLlama carries no market cap, id or ticker for it. The board ranks them by an implied launch value derived from the snapshot's own figures: TVL, priced by how live tokens in the same category trade; seven-day growth; how long the protocol has run; and how many chains it covers.

How the implied value is worked out

implied value = TVL × category multiple × growth factor × maturity factor × spread factor

The category multiple is the median market-cap / TVL of the live-token protocols in that category (thin categories fall back to the market median, ). Growth is clamped to −50…+100% and counts at 0.6 weight. Maturity rises from 0.70 to 1.00 over four years tracked. Each extra chain adds 3%, up to four. No protocol name is special-cased; the same formula scores every row. The implied value is this radar's own claim, never make.fun's.

Read this before you farm

  • “Records no token” is not “has no token.” The snapshot is DefiLlama's record; a protocol on the board may still have a token its record does not carry.
  • Nothing here predicts a launch. The board prices what a token would be worth if the protocol's record stayed as it is. It does not say whether or when a token is issued.
  • Farm plans are generated from the snapshot — category, chains, TVL and age — and state their cost and time. Never pay anyone to claim for you; claim only from the link the protocol itself publishes.
